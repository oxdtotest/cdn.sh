# sing-box Binary Mirror

Unofficial mirror of sing-box binaries for direct download in deployment scripts.

The binaries are downloaded from the official [SagerNet/sing-box](https://github.com/SagerNet/sing-box) releases and redistributed without modification.

## Source

* **Project:** https://github.com/SagerNet/sing-box
* **License:** GPL-3.0
* **Corresponding source:** https://github.com/SagerNet/sing-box

This repository is not affiliated with or endorsed by the sing-box project.

## Usage

Example:

```bash
curl -L -f -o sing-box \
  https://github.com/oxdtotest/cdn.sh/releases/download/v1.12.17/sing-box-linux-amd64

chmod +x sing-box
```
